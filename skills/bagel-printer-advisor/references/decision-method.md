# 决策方法与问询取舍

整理日期：2026-10-17。来源为「贝果陪你选」的纸面问询、模拟访谈和本地小工具迭代；这是方法总结，不是市场排名或真人有效性证据。

| 层 | 关键判断 | 输出怎样变化 |
|---|---|---|
| 环境 | 卧室、长期共处、通风、雨水、宠物接触 | 先处理位置；机型能力不能抵消未解决环境条件 |
| 总预算 | 明确上限、单机/套装、额外配套 | 形成可支付的比较范围；未核价只给方向 |
| 作品尺寸 | 三边、能否拆件、单喷/双喷区域 | 选择打印范围，不用手机或可乐类比承诺能打 |
| 用途 | 装饰、家用、软料、耐热/受力 | 核具体材料、料路与性能要求，不靠用途想象硬件等级 |
| 颜色 | 一次一种、同件自动换、拼装上色 | 决定是否比较换料配置，核时间/耗材取舍 |
| 偏好 | 心仪高配、未来任务、学习投入 | 单独保留；说明额外能力与成本，允许用户自主上高配 |

预算是约束，也体现愿意为方便和扩展付出多少。不能把“预算够”写成“必须买贵的”；也不能只因当前作品小就排除有价值的升级。

## 为什么只留这些问题

- 新手经常不认识材料名，先问“想做什么”和“怎样用”，再在必要时解释材料。
- 每个选择应改变候选、配置、风险提示或下一步；只增加热闹却不改变判断的问题可以删。
- 问卷五轮用于快速定位。顾问式 skill 可跳过已知项、针对关键冲突短追问，不强制走完形式。
- 用户没想好第一件作品时，给“找一个真想打印的模型”的行动，不拿机器参数替代建模学习。
- 全系图表达能力差异，不把产品线画成上市年份、强制升级路径或机器改装路线。

## 已撤回或不应沿用的判断

- 男/女/未成年人或学生身份决定买入门机。
- 小摆件一定买 A1 mini；高预算一定买旗舰；高配在所有维度自动向下兼容。
- 手机长度意味着薄、可乐罐类比意味着尺寸已确认。
- 贴边就一定能/不能打，斜放就一定可行。
- “支持 TPU”同时意味着任何软料都能走AMS和辅助喷嘴。
- 封箱、闻不到气味或普通PLA意味着家庭环境零风险。
- 任意 STL 都可以手机一步打印；机型保证零件承重/耐热/配合精度。
- 将固定过盈毫米数、噪声数字或长期成本估计当官方通用参数。

## 小工具与skill的区别

小工具采用固定预算档的条件路线，适合离线、快速、选择题场景，不是全市场实时优化器。skill 按核实后的事实和具体用户条件比较，不能把某次预算档路由永久固化为购买建议。

当前配置报价全部高于明确上限时，不能轮换另一台未报价机器就写“预算内”；应给预算冲突和核价行动。偏好高配可独立展示，但不挤掉环境提醒。

## 维护

修改题面或推荐条件后用冲突场景复核：高预算小玩具、卧室高配、单色低价/多色套装混价、贴边大件、软料自动换色、全部未知、新品传闻。模拟测试只检验逻辑与可理解性假设，不宣称真人验证。
